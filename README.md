# BTWRD: CHRONICLES V0.1

기존 카드 소환/도감 프로토타입을 보존하면서 `feature/react-vite-battle-mvp` 브랜치에 React + Vite + TypeScript 기반 2D 전투 MVP를 추가한 상태입니다.

## 실행

Node.js 설치 후 다음 명령으로 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소를 열면 됩니다. 배포용 확인은 `npm run build` 후 `npm run preview`를 사용합니다.

전투 MVP 사용 순서:

1. `전투 MVP` 탭 → `새 전투`
2. 손패 카드를 클릭해 좌/중/우 전선에 자동 배치
3. `턴 종료`로 상대 턴으로 전환
4. 두 플레이어가 같은 화면에서 번갈아 조작하는 로컬 핫시트 방식

## 구현된 기본 규칙

- 좌 8 / 중 9 / 우 8의 3성벽 표시
- 플레이어별 25장 덱, 시작 손패 5장
- 턴 마나 2 시작, 턴마다 최대 마나 +1
- 유닛 소환 및 전선 배치, 소환 턴 공격 제한 상태 표시
- 마법 카드 사용 기록 및 묘지 이동
- 턴 종료 시 손패 7장 초과분 자동 버림
- 덱이 비었을 때 드로우 실패 패배 기록
- 기존 24종 카드 데이터와 컬렉션 화면 보존
- 전투 엔진(`src/engine.ts`), 카드 데이터(`src/data/cards.ts`), UI(`src/App.tsx`) 분리
- Three.js/React Three Fiber를 나중에 붙일 수 있도록 전투 상태와 렌더링을 분리

## 아직 미구현 또는 비활성

- 공격 대상 선택, 수비 피해 반감, 도발 우선 처리, 체인/마법 속도, 계승 연속 소환
- 장착/설치마법의 지속 효과 및 활성 마법 존
- 성벽 붕괴 후 무료 긴급 퇴각의 세부 선택 UI
- 우회 공성 A/B/C 및 `???` 합성 소환 횟수
- 3D 성벽 붕괴/소환 연출

위 항목들은 전투 화면 하단에 테스트 범위로 표시하며 정식 규칙으로 확정하지 않았습니다. 원격 `main`에는 반영하지 않았고 작업 브랜치에서만 확인할 수 있습니다.
